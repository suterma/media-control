# media-control
Various media controller implementations as support for [Replayer](https://replayer.app).

## Windows (Experimental)

A custom [AutoHotkey](https://www.autohotkey.com/) mapping is provided. It maps some of the existing [keyboard shortcuts](https://replayer.app/en/documentation/keyboard-shortcuts) to Windows virtual key codes for media control.

Currently, only Play/Pause is (experimentally) supported, as Replayer does not yet provide extensive media control itself.
